Demos

Five complete programs. Each one runs on first boot.

These are the five programs preloaded on every SwayForm robot. Students read the code, run it, modify it, and eventually write their own. Each demo has full source code with line-by-line explanation.

01

Wave

Smooth 5-keyframe arm wave using smoothstep interpolation at 20 Hz. The canonical first demo — shows the full node-to-servo path in one motion.

Students learn
Joint commandsKeyframe timing20 Hz loop
● Beginner right arm chain
02

Greet

Head turn, arm raise, and spoken output triggered by a ROS 2 String topic. Students see how one published message coordinates multiple systems at once.

Students learn
Topics + subscribersAudio outputCoordinated motion
● Beginner neck + arm + speaker
03

Face Track

Haar cascade detection drives neck pan/tilt via a proportional controller. The robot holds its gaze on a detected face with a dead zone to prevent jitter.

Students learn
Haar cascadeProportional controlDead zones
● Intermediate D435i · neck joints
04

Proximity

Ultrasonic sensor triggers three behavioral zones — idle, alert, and close — with hysteresis to prevent rapid switching between states.

Students learn
Sensor thresholdsHysteresisState machine
● Beginner HC-SR04 · full body
05

Present

Subscribes to slide-advance commands and maps each to a gesture + spoken callout. Combines motion, audio, and topic-driven control in a single behavior.

Students learn
Multi-system behaviorEvent-drivenTTS
● Intermediate arm + neck + speaker
06

Finger Control

Individual finger joints independently commanded via keyboard input mapped to ROS 2 topics. Each key opens or closes one finger — 5 joints addressed simultaneously.

Students learn
Individual joint addressingSimultaneous commandsFine servo control
● Beginner finger servos × 5
07

Object Tracking

HSV color segmentation isolates a colored object in the camera feed. Centroid calculation drives neck pan/tilt to keep the object centered in frame.

Students learn
HSV color spaceContour detectionCamera feedback loop
● Intermediate D435i · neck joints
08
Prototype

Pick / Place

Locates an ArUco-marked object using depth camera, positions the arm above it, and closes the fingers. Early-stage prototype — no force feedback. Shown honestly as work in progress.

Students learn
ArUco detectionCoordinate framesMulti-phase motionOpen-loop limits
● Advanced D435i · right arm · fingers
Run any demo in 30 seconds
$ ssh swayform@<robot-ip>
$ source ~/swayform_ws/install/setup.bash
$ ros2 run swayform_demos wave_demo

All demos are preinstalled. No build step required. See Chapter 1.3 in the Learning Hub for the full first-session walkthrough.
