Curriculum

The same path students see in the Learning Portal.

Twenty foundation labs, then about ten behavior sections. Every lab has starter code, step-by-step instructions and a debug checklist, and runs on real hardware.

Each section follows one behavior, such as a wave, from its first line of code to a full program. Early labs teach one small piece. Later labs add concepts and how the robot is built and why. By about lab 8 students understand most of it, and by lab 10–12 they write enough of the code on their own.

Students write more of the code in each section: about 25% in the first section, about 55% by the seventh, and about 75% by the tenth. Lab titles will be finalized as development continues.

Two tracks, one path · Planned

A Middle School track and a High School track.

Two curriculums at different difficulty levels, with overlapping features and skills, that all connect together at the end.

Middle School track
Lower difficulty, same robot.

The same demos, joints, and ROS 2 ideas, paced for younger students — still real code moving real hardware.

Overlapping features and skills

Both tracks use the same Learning Portal, the same pre-installed demos, the same foundation labs and the same behavior sections.

It all connects at the end

The two tracks converge at the end of the path, in the final sections.

High School track
Higher difficulty, deeper systems.

The same skills pushed further — more original code and more of the perception, state-machine, and multi-node work that leads into the project track.

The path in the Learning Portal today is the foundation both tracks are built from. Track-specific lab versions are planned and will be released as development continues.

How it works

Code reaches the robot one program at a time.

Student code never reaches the motors directly. While one program runs, everyone else keeps coding.

01
Read the lesson

Short sections in the portal's textbook.

02
Write or edit code

One idea at a time, right before it's used.

03
Join the queue

Correct code waits its turn.

04
Teacher approves

A teacher or club leader approves each run.

05
Safety check

Joint, speed and timing limits are checked before anything moves.

06
The robot runs it

Students watch their code work in person.
