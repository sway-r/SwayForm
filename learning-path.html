Two tracks, one path · Planned

A Middle School track and a High School track.

SwayForm is built for schools — including, but not limited to, middle schools and high schools. The two tracks follow the same seven-section path at different difficulty levels, share overlapping features and skills, and connect together at the end.

Middle School track
Lower difficulty, same robot.

The same demos, joints, and ROS 2 ideas, paced for younger students — still real code moving real hardware.

Overlapping features and skills

Both tracks use the same Learning Portal, the same pre-installed demos, the same joint commands and safety rules, and the same four levels — Control, React, Perceive, Create.

It all connects at the end

The two tracks converge at the end of the path, in Level 4 — Create, where every student builds toward the same final showcase.

High School track
Higher difficulty, deeper systems.

The same skills pushed further — more original code and more of the perception, state-machine, and multi-node work that leads into the project track.

The path in the Learning Portal today is the foundation both tracks are built from. Track-specific lab versions are planned and will be released as development continues.
