Setup requirements
✓
Power outlet — standard 120V. The robot runs on a 12V 5A DC adapter included in the box.
✓
WiFi network — students connect laptops and robot to the same network. A $30 hotspot router works fine if school WiFi blocks SSH.
✓
Student laptops — any OS. VS Code + Remote-SSH extension. No special software beyond that.
✓
30cm clearance on all sides when powered. Tabletop or dedicated cart. No mounting required.
✗
No server, no cloud subscription, no external internet connection required.
How many robots do you need?
Robotics club (6–15 students): 1 robot. Teams rotate.
Class of 20–28 students: 5–7 robots. One per group of 4.
STEM outreach / showcase: 1–2 robots for demonstration.
Engineering program (multi-class): 8–12 robots shared across sections.

Classroom management model

Four rotating roles per group: Driver (runs commands), Coder (writes code), Observer (logs behavior), Documenter (writes notes). Clear responsibilities prevent chaos.
